### 2.1 前端结构
| 模块名称 | 职责说明 | 关键点 |

## 3. 操作用法与反馈说明

### 3.1 访问欢迎页面
* **操作用法**：
  1. 打开浏览器，访问 `https://www.wushuang.asia/`。
  2. 页面加载完成后，点击任意处开始交互。
* **反馈结果**：
  * 页面显示欢迎信息，背景音乐自动播放（若浏览器允许）。
  * 鼠标指针变为自定义图标，提升视觉体验。

### 3.2 提交秘密告白
* **操作用法**：
  1. 点击页面上的“想偷偷对会长说的话”按钮。
  2. 在弹出的表单中输入留言内容。
  3. 点击“确定”按钮提交。
* **反馈结果**：
  * **成功**：显示绿色提示“发送成功！会长会看到的✨”，并自动关闭弹窗。
  * **失败**：若输入为空，显示警告“留言内容不能为空哦”；若网络异常，显示错误提示。

### 3.3 为会长点赞
* **操作用法**：
  1. 点击页面底部的“为会长点赞”按钮。
* **反馈结果**：
  * **成功**：显示绿色提示“点赞成功 ❤️ 感谢支持会长！”，并更新点赞数。
  * **失败**：若网络异常，显示错误提示“点赞失败，网络开小差了～”。

### 3.4 查看用户列表
* **操作用法**：
  1. 页面加载完成后，用户列表会自动显示在屏幕中。
* **反馈结果**：
  * 显示社区成员昵称列表，支持滚动查看。(像弹幕一样噢~)

## 4. 项目部署与维护

### 4.1 本地开发
1. **克隆项目**：
   ```bash
   git clone https://github.com/wuxuanok/TianXiaWuShuang.git
   ```
2. **进入项目目录**：
   ```bash
   cd TianXiaWuShuang
   ```
3. **启动本地服务器**：
   - 使用 VS Code Live Server 或其他本地服务器工具，打开 `tianxiawushuang_frontend/index.html`。

### 4.2 部署说明
- **前端部署**：将 `tianxiawushuang_frontend` 目录下的文件部署到静态网站服务器。
- **后端部署**：后端代码位于 `tianxiawushuang_backend` 目录，需部署到 Java 服务器环境。

### 4.3 常见问题与解决方案
| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| 鼠标图标不显示 | 图标路径错误或文件缺失 | 确保 `cursor/1.cur` 文件存在，路径引用正确 |
| 音乐不自动播放 | 浏览器限制自动播放 | 点击页面任意处后手动播放音乐 |
| 点赞/留言失败 | 网络异常或后端服务不可用 | 检查网络连接，确保后端服务正常运行 |
